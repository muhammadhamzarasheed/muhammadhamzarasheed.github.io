# muhammadhamza.co.uk

Personal site for Muhammad Hamza, Assessment Lead at UK Management College.

Single self-contained page. `index.html` holds the markup, styles and the small
reveal script. The only external request is the Google Fonts stylesheet.

## Hosting

Served by GitHub Pages from the root of this repository. `CNAME` pins the custom
domain to `muhammadhamza.co.uk`. Do not delete that file: GitHub Pages reads it
on every build, and removing it drops the custom domain.

## Editing

Edit `index.html`, commit, push. The site rebuilds in about a minute.

Content is drawn from the LinkedIn profile at
`linkedin.com/in/muhammadhamzarasheed`. When a role, qualification or ACCA paper
count changes there, update it here too so the two do not drift apart.

## House style

No em dashes or en dashes anywhere in the copy. Date ranges are written
"Feb 2025 to Jul 2026".
